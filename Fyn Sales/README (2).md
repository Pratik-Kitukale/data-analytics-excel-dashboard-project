# FNP Sales Analysis Dashboard 📊

## Overview
This project features an interactive sales dashboard built in Microsoft Excel for analyzing sales performance. The dashboard provides deep insights into sales trends, customer purchasing behavior, and delivery efficiency, empowering data-driven decision-making.

## Key Performance Indicators (KPIs)
The top section of the dashboard tracks critical metrics:
- **Total Sales:** ₹ 3.52 M
- **Max Sales:** ₹ 9,885.00
- **Total Orders:** 1,000
- **Average Spent:** ₹ 3.52 K
- **Average Order Delivery Time:** ~5.53 Days

## Visualizations & Insights
The dashboard incorporates several dynamic charts to breakdown the data:
- **Sales by Occasions & Category:** Bar charts highlighting the most profitable events (e.g., Anniversary, Raksha Bandhan) and product categories (e.g., Colors, Soft Toys, Sweets).
- **Top Cities by Orders:** A column chart identifying the highest-demand geographical regions.
- **Revenue by Hour & Monthly Revenue:** Line graphs displaying time-series trends to identify peak sales hours and seasonal performance.
- **Top 5 Products by Revenue:** A pie chart detailing the specific items driving the most revenue.

## Interactivity
Users can easily slice and dice the data using built-in filters (Slicers) located on the left panel:
- **Occasions** (Anniversary, Birthday, Diwali, Holi, Raksha Bandhan, Valentine's Day)
- **Category** (Cake, Colors, Mugs, Plants, Soft Toys, Sweets)
- **Order Date & Delivery Date** (Timeline sliders)
- **City** 

## Tools Used
- **Microsoft Excel:** Data Cleaning, Pivot Tables, Advanced Charting, Slicers, Dashboard UI Design.

## How to Use
1. Clone this repository or download the `.xlsx` file.
2. Open the file in Microsoft Excel.
3. Use the navigation buttons (Dashboard, Analysis, Data) or the slicers on the left to interact with the visual reports and filter by specific categories or timeframes.
