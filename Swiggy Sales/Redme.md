# Swiggy Sales Analysis - Excel Dashboard

## 📌 Project Overview
This project is an interactive Data Analytics dashboard created in Microsoft Excel to analyze Swiggy's sales data. It provides actionable insights into sales trends, customer ratings, order values, and geographical performance to help understand consumer behavior and business growth.

## 📊 Key Metrics Highlighted
Based on the full dataset analysis, the dashboard showcases:
- **Total Sales:** ₹53.01M
- **Total Orders:** 197.43K
- **Average Rating:** 4.34 (Rating Count: 5.59M)
- **Average Order Value:** ₹268.51

## 🛠️ Dashboard Features
- **Interactive Slicers:** Filter data dynamically by Months, State, Category, and Restaurant Name.
- **Trend Analysis:** Visual representations of Monthly, Weekly, and Daily sales trends.
- **Geographical Insights:** A heatmap/map chart displaying sales distribution across various Indian states.
- **Categorical Breakdown:** Donut chart analyzing sales by food type (Veg vs. Non-Veg) and bar charts for top-performing cities.

## 🚀 How to Use
1. Download the `Swiggy Raw Data Excel.xlsx` file.
2. Open it in Microsoft Excel (2016 or newer recommended for map charts).
3. Navigate to the **Dashboard** sheet.
4. Use the slicers on the left panel to interact with the data and explore different metrics.
